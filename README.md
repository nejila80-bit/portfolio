# Nejila — Personal Portfolio Website 🌷

A colourful, aesthetic personal portfolio website made for **Nejila** using HTML, CSS, and JavaScript. The design combines soft colours, playful decorative details, and gentle animations to introduce the person behind the portfolio and showcase skills and sample projects.

## ✨ Features

- **Home section** with a short introduction and links to other sections
- **About section** to share personal interests and goals
- **Projects section** with sample project cards
- **Skills section** highlighting web development and creative skills
- **Contact section** with email and social media links
- **Colourful, pastel-inspired design** with floral and playful details
- **Responsive layout** for desktop, tablet, and mobile screens
- **Mobile navigation menu**
- **Scroll reveal animations** for selected sections
- **Back-to-top button**
- **Automatically updated copyright year**
- **Reduced-motion support** for visitors who prefer fewer animations

## 🛠️ Technologies Used

- **HTML5** — structures the page and its content
- **CSS3** — controls the layout, colours, typography, responsiveness, and animations
- **JavaScript** — powers the mobile menu, scroll effects, back-to-top button, and current year

All HTML, CSS, and JavaScript are contained in `index.html`, so you do not need to install packages or run a build command.

## 🚀 How to Run

1. Download or clone the project.
2. Keep `index.html` and `README.md` in the same folder.
3. Open `index.html` in a web browser.

### Optional: Run with VS Code Live Server

1. Open the project folder in Visual Studio Code.
2. Install the **Live Server** extension if you do not already have it.
3. Right-click `index.html` and select **Open with Live Server**.

## 🎨 Customise the Portfolio

Before publishing the website, open `index.html` in a code editor and update the sample details:

1. **Name and introduction:** Replace any placeholder text such as `Your Name` with your preferred name and bio.
2. **Email address:** Replace the example email in the contact button with your real email address.
3. **Social media links:** Update the GitHub, LinkedIn, and Instagram links to your own profiles.
4. **Projects:** Replace the sample project titles and descriptions with your actual work. Add project links or screenshots when available.
5. **Skills:** Edit the skills list to reflect the technologies and abilities you have learned.
6. **Design:** Adjust the colours, text, spacing, and decorative elements in the CSS to make the site your own.
